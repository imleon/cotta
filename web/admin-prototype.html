Static HTML Prototype · Cotta Admin

用后台视角看 Cotta 的主体、抓手、现场与 Job

这是一张独立静态原型页，不依赖 Vue 运行时。它把 Cotta 的五个核心模型按你的语义重新组织：Agent 是主体，Channel 是抓手，Connector 是抓手的连接器，Session 是工作现场，Run 是 Job。第一版目标不是接真实数据，而是先让信息架构和关系表达变得一眼能懂。

Model Glossary

用一句话解释五个对象，保证不看架构文档也能理解这页在说什么。

  • Agent：具有独立人格和工作能力的主体。
  • Channel：抓手，代表一个具体入口或交互窗口。
  • Connector：抓手的连接器，负责接外部平台能力。
  • Session：工作现场，承载上下文和状态。
  • Run：一次具体 Job 的执行记录。

This prototype should answer

如果这张静态页有效，用户应该只看页面就能回答下面的问题。

  • 一个 Connector 下面挂了哪些 Channel？
  • 某个 Channel 默认归属哪个 Agent？
  • 一个 Session 当前是不是 managed，是否有 worker 和 active run？
  • 一个 Session 最近的 Job 是成功、阻塞还是失败？
  • foreign session 与 managed session 的差别是什么？
